# Support

## Obtenir de l'aide

Ce bucket est mis à jour exclusivement par les workflows des dépôts qui produisent les paquets. Les pull requests manuelles ne sont pas acceptées.

Pour obtenir de l'aide sur un outil distribué, consultez le dépôt source indiqué par son manifest. Pour les problèmes propres à la distribution Scoop de ce bucket, consultez :

- les [issues ouvertes](../../issues) et [fermées](../../issues?q=is%3Aissue+is%3Aclosed) ;
- les [Discussions](../../discussions) pour les questions générales.

## Signaler un problème de distribution

Utilisez le [modèle de rapport de bug](../../issues/new?template=bug_report.yml) pour signaler un problème d'installation, de manifest ou de distribution.

## Demander une modification

Utilisez le [modèle de demande de fonctionnalité](../../issues/new?template=feature_request.yml) pour une demande concernant ce bucket. Les changements retenus sont publiés par les workflows des dépôts producteurs.

## Ce à quoi vous pouvez vous attendre

- Ce projet est maintenu sur la base du meilleur effort possible.
- Aucun délai de réponse ni SLA de support n'est garanti.
- Les problèmes de sécurité doivent être signalés de manière privée conformément à [SECURITY.md](SECURITY.md).
