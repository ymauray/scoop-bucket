# Politique de sécurité

Cette politique couvre les manifests de ce bucket et leur distribution Scoop. Pour une vulnérabilité dans un outil distribué, signalez-la au dépôt source de cet outil.

## Versions prises en charge

Seule la dernière version est prise en charge. Les correctifs de sécurité sont publiés sous forme de versions de patch.

## Signaler une vulnérabilité

**N'ouvrez pas d'issue publique pour les vulnérabilités de sécurité.**

[Signalez les vulnérabilités de manière privée](../../security/advisories/new). Incluez :

- Les étapes pour reproduire le problème
- Le manifest concerné
- Les versions affectées
- L'impact potentiel

Ce projet est maintenu sur la base du meilleur effort possible. Aucun délai de réponse n'est garanti pour les signalements de sécurité.
